GitHub Personal Access Token
Why do I need a token?
Without a token, GitHub limits API requests to 60 per hour. With a token, you get 5,000 requests per hour.
Create a token at github.com/settings/tokens
Select scope: public_repo
Note: Your token is stored locally in your browser and never sent to any server.
